# Three-Channel Audio Mixer Using an Op-Amp (Multisim Lab)

An interactive project report and simulation overview for a **Three-Channel Audio Mixer** utilizing operational amplifiers.

🌐 **Live Demo:** [https://bgmonikkasri-dev.github.io/three-channel-audio-mixer/](https://bgmonikkasri-dev.github.io/three-channel-audio-mixer/)

## Overview
Design and simulation of an analog electronics circuit that combines three independent audio signals into a single unified output, allowing independent level/gain adjustments for each input channel.

## Contents
- **[three_channel_audio_mixer_multisim.html](./three_channel_audio_mixer_multisim.html)**: Interactive report including circuit schematics, operational amplifier formulas, simulation analysis, and interactive comprehension quiz.

## Key Features
- **Independent Channel Control**: Separate gain scaling across all 3 audio channels using potentiometers / summing resistors.
- **Op-Amp Inverting Summing Amplifier Configuration**: Minimizes inter-channel crosstalk with virtual ground summing.
- **Multisim Simulation Results**: Detailed frequency response and waveform behavior.
