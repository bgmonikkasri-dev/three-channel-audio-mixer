Three-Channel Audio Mixer Using an Op-Amp

Design and simulate a circuit that combines three independent audio signals into one output, while allowing the contribution of each channel to be adjusted separately.

Aim and learning objectives

To design an op-amp audio mixer with three input signals and individual volume controls, then observe the combined output in NI Multisim.

  • Understand the inverting summing-amplifier configuration.
  • Use one potentiometer per input to control its signal contribution.
  • Combine three signals at a common summing node.
  • Observe the output waveform using an oscilloscope.
Core concept: all three input channels feed the same inverting input through separate resistors. The feedback resistor returns the output to that same node.

Expected behaviour

Working principle

1. Three separate channels

Each source passes through its own potentiometer. Turning a potentiometer changes that source's level before it reaches its input resistor.

2. Summing node

The three 10 kΩ input resistors meet at the inverting input (pin 2). With negative feedback, the op-amp keeps this node near virtual ground when operating linearly.

3. Negative feedback

The feedback resistor Rf connects the output to pin 2. Its value relative to the input resistors determines each channel's voltage gain.

4. Mixed output

The output is the inverted sum of the weighted inputs. If two or more sources have different frequencies, the displayed output contains their combined waveform.

Vout ≈ −Rf (V1/R1 + V2/R2 + V3/R3)

For equal 10 kΩ input resistors and Rf = 10 kΩ, the ideal inverting gain for each channel is −1, assuming the voltages shown are the signals arriving at the input resistors.

Key equations

Vout = −(Rf/R1)V1 − (Rf/R2)V2 − (Rf/R3)V3

Here V1, V2 and V3 are the channel voltages at the input resistors, R1–R3 are the input resistors, and Rf is the feedback resistor. This ideal equation assumes the op-amp is operating within its linear range and input currents are negligible.

For Rf = R1 = R2 = R3 = 10 kΩ:   Vout = −(V1 + V2 + V3)

The potentiometers scale the original source signals, so use the actual post-control voltages in the equation. The minus sign indicates 180° inversion for each sinusoidal component in the ideal inverting configuration.

Multisim procedure

  1. Place one UA741 op-amp, three sine-wave sources, three 10 kΩ potentiometers, three 10 kΩ input resistors, and one 10 kΩ feedback resistor.
  2. For each channel, wire source → volume potentiometer → optional 10 µF coupling capacitor → 10 kΩ input resistor → common summing node at pin 2.
  3. Connect Rf from output pin 6 to the same summing node. Do not connect the feedback resistor to pin 3.
  4. Connect pin 3 to ground. Connect pin 7 to +12 V and pin 4 to −12 V. Ensure the supplies share the correct common reference.
  5. Connect all source grounds to the common circuit ground.
  6. Connect the oscilloscope ground to common ground. Use separate scope channels to inspect the inputs and output where available.
  7. Start with small sine amplitudes, for example 0.2 V peak, and use 1 kHz for each source initially. Then try different frequencies to see the combined waveform.
  8. Adjust one potentiometer at a time and observe the output. If the output is flat or clipped, check the supply rails, pinout, feedback loop, ground, and source amplitudes.
GATE-style practice

GATE-style questions related to the circuit

GATE Q1 · Ideal summing amplifier

Rf = R1 = R2 = R3 = 10 kΩ. The three input voltages are 0.2 V, 0.1 V and 0.3 V. What is the ideal output?

Options: A) +0.6 V   B) −0.6 V   C) −0.2 V   D) +1.8 V

Answer: B) −0.6 V. Vout = −(V1 + V2 + V3) for equal resistors.

GATE Q2 · Virtual ground

With negative feedback and the non-inverting input grounded, the inverting summing node is approximately:

Options: A) +12 V   B) −12 V   C) 0 V (virtual ground)   D) equal to the output

Answer: C. The op-amp keeps the input difference close to zero while operating linearly.

GATE Q3 · Gain ratio

If Rf = 20 kΩ and an input resistor is 10 kΩ, what is the ideal gain magnitude from that input considered alone?

Options: A) 0.5   B) 1   C) 2   D) 10

Answer: C) 2. Gain magnitude = Rf/Rin = 20/10.

GATE Q4 · Superposition

Three sinusoidal signals of different frequencies are summed in the linear region. The output contains:

Options: A) Only the highest frequency   B) Only the lowest frequency   C) A weighted combination of all three   D) No AC component

Answer: C. A linear amplifier produces the weighted sum of its input signals.

GATE Q5 · Saturation

If the required output exceeds the op-amp's available output swing, what is likely?

Options: A) Clipping/saturation   B) All input frequencies become equal   C) Feedback resistance becomes zero   D) Circuit becomes passive

Answer: A. The output is limited by the op-amp and its supply rails.

Core electronics interview practice

Core-company questions based on this circuit

Try answering each question before opening its explanation. These are common interview-style prompts for electronics, hardware, embedded and test roles.

Core Q1 · Why use an op-amp in an audio mixer?

It combines several input signals into a controlled weighted sum and, with negative feedback, provides predictable gain.

Core Q2 · Why is it called an inverting summing amplifier?

Signals enter the inverting input through separate resistors, and the output is the negative weighted sum of those inputs.

Core Q3 · What does the feedback resistor do?

It provides negative feedback and sets each channel's closed-loop gain relative to its input resistor.

Core Q4 · Why use one potentiometer per channel?

Each potentiometer independently adjusts the level of one audio source before it is summed with the others.

Core Q5 · What do coupling capacitors do?

They block DC between stages while passing AC. Their value affects low-frequency response; they may be omitted in an ideal zero-offset simulation.

Core Q6 · Explain virtual ground.

Negative feedback keeps the inverting input near the grounded non-inverting input, so the summing node is approximately 0 V without being directly grounded.

Core Q7 · What if one input is disconnected?

The other channels can still contribute, provided the unused input does not float or introduce noise.

Core Q8 · Why might the output be distorted?

Possible causes include saturation, excessive input amplitude, incorrect supply wiring, a broken feedback path, heavy loading, or bandwidth/slew-rate limits.

Core Q9 · Why use an oscilloscope?

It shows the input and output waveforms and helps reveal amplitude changes, clipping, missing signals and unexpected offsets.

Core Q10 · How do you verify each channel?

Test one source at a time with the others set to zero, observe the output, and adjust that channel's potentiometer. Repeat for all channels, then test them together.

Conclusion

A three-channel audio mixer can be implemented with an op-amp configured as an inverting summing amplifier. Separate potentiometers provide independent channel-level adjustment, and the feedback network determines the summing gain. Multisim's oscilloscope can be used to compare individual inputs with the combined output.
